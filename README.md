# 周末有班
大学生周末兼职撮合交互原型。纯 HTML/CSS/JS，无构建依赖。

## GitHub Pages
将本目录上传至公开仓库 main 分支，在 Settings → Pages → Source 选择 GitHub Actions。推送后工作流部署 dist。持续更新同一仓库即可保持 URL 不变。

## 产品与演示
发现兼职 → 选择时间与距离 → 查看薪资及职责 → 报名 → 商家工作台确认录用 → 学生模拟完工 → 商家模拟结算。
支持关键词搜索、收藏、时间冲突拦截、重复报名拦截、取消申请、发布岗位和本地持久化。

## 边界
所有岗位与身份均为演示，数据只在当前浏览器，不跨设备共享。不存在真实实名认证、支付、消息通知或客服。发布职位默认示例距离 1km、餐饮分类和 24h 结算。真实上线需要后端身份及角色权限、岗位审核、实际地址距离计算、结算约定及争议处理。不要录入个人敏感信息。
