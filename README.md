# 周末有班

大学生周末兼职撮合交互原型，纯 HTML/CSS/JS。

## 在线访问
https://searchqianqian.github.io/weekend-match/

## 发布与更新
GitHub Pages 已配置为 Deploy from a branch → main → / (root)。修改根目录 index.html 与 app.js 并提交 main，GitHub 会自动重新部署，网址保持不变。dist 目录是初始备份，不是当前发布源。不要重命名仓库或更换账号名。

## 演示流程
发现兼职 → 筛选时间与距离 → 查看岗位 → 报名 → 商家工作台确认录用 → 学生模拟完工 → 商家模拟结算。
支持搜索、收藏、重复报名和时间冲突拦截、取消申请、发布岗位与浏览器本地持久化。

## 原型边界
所有岗位与身份均为演示，数据仅存在当前浏览器。不提供真实实名认证、支付、消息或客服。发布岗位默认示例距离 1km、餐饮分类与24h结算。真实上线还需要后端、权限、审核、地图距离及争议处理。不要输入敏感个人信息。
